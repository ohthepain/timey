# Reference installed Factory content

Factory ships its built-in flows and blocks with the installation. A project
uses the installed Markdown directly so upgrades have one source of defaults
and project setup needs no copies. Custom flows and overrides belong to the
project and can be reviewed in its Git history.

See the [sidebar folder design](../plans/factory-sidebar-folders.md) for how
the sidebar presents installed and project content.
