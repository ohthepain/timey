# Use real folders for issue organization

One sidebar tree shows real directories. A project directory with a Factory
settings Markdown file can show its files, assigned issues, and issue actions
in one place. This lets a team keep material such as release checklists next to
the relevant issues while their reports stay in the issue queue.

Keep a stable folder ID in the settings file and store each assignment with
its issue report. Renaming the directory preserves assignments. Committing the
settings and sharing the issue reports lets teammates see the same membership.

See the [sidebar folder design](../plans/factory-sidebar-folders.md) for folder
behavior and migration.
