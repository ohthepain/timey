# Separate closed issues from the active queue

The active queue contains open issues. Move closed reports to a separate folder so people can browse them without adding them to routine queue reads and model context. Archiving retains a closed report on the initiating machine and reserves its display number. Shared closure and archive removal land through human-reviewed report PRs, and a previously published report remains in Git history.

See the [closed issue design](../plans/archive-closed-issues.md) for migration, bulk actions, and restore.
