# Factory visual direction

The new-issue dialog establishes a direction for future factory surfaces, inspired
by the static product screens in [RedLink](https://ux-design-awards.com/winners/2026-2-redlink).
Use soft lavender canvases, white cards, vivid indigo primary actions and restrained
coral accents. Keep body text dark and secondary text readable. Color supports
written labels and must never carry status or authorization on its own.

Use generous spacing, rounded cards and a strong heading to make a focused task
inviting. Group related choices inside cards. Reserve gradients for introductory
areas; keep working surfaces quiet. Prefer one prominent action with a clearly
named secondary action. Keep keyboard focus visible, native form semantics,
44px button targets and a layout that fits small screens and scrolls vertically.

The new-issue dialog separates description, model, delivery choices and actions.
Save captures issues for later; Go saves and explicitly starts each captured issue.
The model selection applies to new issue work (including opt-in grilling), while
capture assessment uses the configured capture model. Merge off selects Full Stop;
Merge on selects Full Send with the existing protected Merge control and checks.
Grilling is discussion-first, so it disables Go; Save can start grilling.

Start failures retain the created issue and link to its status and Continue control.
They must not prompt users to create a duplicate. Existing strategy, review,
publication, merge and acceptance boundaries remain authoritative. This direction
is a starting point for future work, not a mandate to restyle unrelated screens.
