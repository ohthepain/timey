## Agent skills

### Issue tracker

Track work in `.issues/` using `$issue`, `$issues`, and `$fix-issues`.
Before creating, reading, or updating tickets, read
`docs/agents/issue-tracker.md`.

For any skill that uses triage roles, publishes specs/tickets, or implements
tracked work, read that tracker document first and follow this repo's adapter
in place of the skill's default tracker paths, status fields, and commit or
closure instructions. Matt Pocock triage roles are separate metadata; read
`docs/agents/triage-labels.md` before applying them.

### Domain docs

Before exploring domain concepts or changing architecture, read
`docs/agents/domain.md`.
