## Original request

Add a "Full Send" option. Feel free to give it a better name, but that's what Theo called it. This means that the user is leaving and wants to trust the agent to make decisions all the way to a merged PR. The user is granting the agent to do as much as possible, including merging, creating PRs, fixing tests, removing tests. All of the work can be done in the Implement role.
Steps:

1. Finish the work. If you are in the default branch then create a branch first.
2. Prove it. Get proof for every change you made.
3. File the PR. Draft is okay if necessary due to factors beyond your control
4. Merge when the merge gate passes
5. Report. Report in your final message: The PR link, the merge commit, your proof, and every design decision you made, and every test you had to fix or remove
