## Original request

Replace gear menu contents with categorized project Settings

Create a ChatGPT-style settings window, opened by the existing gear icon button, with sidebar categories and a bespoke page per category. Each page should have a direct URL. Everything is scoped to the project where Factory is installed. Keep the old Admin page available.

Agreed pages

Issues:
Editable Project defaults: Target branch, Skill, Model, Effort, Selection strategy. Show effective values with stored identifiers and their source beneath each control. Examples discussed: number_2; poteto-mode; GPT-6.1 Sol (gpt-6.1-sol); Medium (medium); Different blast radii (different-blast-radii), all sourced from folder.md. Read actual values, do not hardcode examples. Preserve existing inheritance and folder/issue overrides.

Issue Lifecycle:
Carry over existing lifecycle configuration. Identify the triage labels Markdown file, show its path and an Open file action. Show the user override path, whether an override exists, and effective labels with their sources.
Include read-only Human input information linked to the actual project adapter source:
- Required human input is checked before dependent work proceeds.
- Closing a fixed issue requires explicit user acceptance.
- Local progress commits can retain outstanding human checks.
- Each issue keeps its own requests and approvals. There is no policy preset selector.
Derive policy details from actual configuration.

Git:
Show credential references and GitHub App connection and permissions.
Buttons: Prune Worktrees; Clean up remote branches; Clean up local branches; Delete archived issues. Reuse existing Admin operations, previews, confirmations and guards. Leave the existing Admin page and its operations available.

Issue Storage:
Configure only existing storage providers. Do not implement PostgreSQL or DynamoDB support yet. Show current provider, applicable ordinary configuration, status and connection tests. Preserve storage behavior; saving must not silently migrate issues.

Secrets for Git and Issue Storage:
Show actual configured secret names/references and availability only. Users cannot edit secret names or values. Resolve secrets through existing mechanisms. Provide a Test connection action per configured connection, reporting authentication and required permission results without exposing secret values. Ordinary non-secret configuration is editable where supported.

AI Skills sidebar group:
- Skills page: installed skills, required skill libraries, and each library's availability.
- Prompts page: separate editors for Project chat prompts, Issue chat prompts, Report chat prompts, Investigation chat prompts. Show effective prompt and source, allow project overrides and Restore default. All edits apply to this installed project only.

Hotkeys:
List supported actions and actual current key combinations, and allow editing:
- Dictate HOT
- Dictate COLD
- New Note
- New Issue
Duplicate Factory hotkeys block saving. Include Restore defaults; restored values only apply after saving.

Saving and navigation:
Explicit Save buttons. Leaving a page or closing Settings with unsaved changes offers Save / Discard / Cancel. Save validates and persists before navigation completes; Cancel retains the draft. Restore default actions use the same draft/save flow.

Acceptance:
- Existing gear opens the new settings window; all agreed pages are directly addressable.
- Settings and edits apply only to the installed project.
- Explicit saving, unsaved-change handling, hotkey editing, duplicate blocking and saved default restoration work.
- Secrets remain read-only references and tests never expose values.
- Project defaults, inheritance, lifecycle policies and maintenance safeguards retain existing semantics.
- Old Admin remains available. No new PostgreSQL or DynamoDB backend.
- Update affected docs and verify actual UI behavior.

Capture the decisions agreed in project Discuss. Create the issue only, leaving it idle; do not start implementation. The attached local note about Issues and Notes typography is separate and adds no scope to this settings issue.
