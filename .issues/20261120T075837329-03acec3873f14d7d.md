## Original request

Project chat should open scrolled to the bottom

When first opening the page or opening the project's Discuss/chat tab, the conversation does not start at the bottom. The user has to scroll down manually every time to reach the latest messages.

Expected behavior: once the existing conversation has loaded, initially opening the project chat shows the latest messages at the bottom automatically. Initial loading and rendering should not leave the chat above the latest message. After initial opening, preserve the user's ability to scroll up and read older messages without being pulled back to the bottom.

Verification: open a project conversation long enough to require scrolling, including after a page reload and when returning to the project chat tab, and confirm the latest messages are visible without manual scrolling.
