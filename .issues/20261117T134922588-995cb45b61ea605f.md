## Original request

Let's add settings to folders. The only setting to start with should be default target branch. You should still be able to set the target for individual issues within the folder to target branches other than the default for the folder. Only issues that target the default branch for the folder can be grouped. The only other setting for the folder (and this should be topmost in the folder ui) is "is default folder". This means that when the user creates a new issue it will go into this folder by default.
