## Original request

local todos feature. this is for Grabbing quick notes that you don't want to forget without interrupting your flow They should be in a separate section in the left column. They should be stored in a local folder that is not version controlled It should be based on a skill called local-note. Ask questions and don't implement anything yet.

## Clarification and approval

The user settled the behavior through this chat, then authorized implementation
with “LFG”. Notes and checkbox todos belong to one installed project, shared
across its branches/worktrees. Capture is available inline, by keyboard shortcut
and through the new `local-note` skill, saving the person's words immediately.
Edit, complete, delete and manual ordering are included.

Discuss prepares the project chat with the note as context and no AI answer,
then fills the composer with an editable suggested first prompt. Turn into issue
prefills the existing creation form and continues discussion. After creation,
the response links to the new issue and offers deletion of the original note;
deletion is optional and explicit.

See [the agreed design](../docs/plans/local-notes.md). Reproduction is inapplicable
to this new feature. A separate prototype is unnecessary because capture, issue
creation and project discussion reuse existing controls with settled behavior.
