name: dnextnote
description: Delete the note being discussed and open the next note in sidebar order.
metadata:
  note-discussion-only: 'true'
---

Use this skill only in a Project Discuss conversation about a current local note.
Send `/dnextnote` or select the skill and send it by itself. Factory handles the
deletion and navigation directly. If there is no next note, Factory reports that
after deleting the current note. Keep any linked issue.
